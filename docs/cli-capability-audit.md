# Historical CLI capability audit

PORT-005 inventories the CLI at Clio commit `75c7c09e962ef15506ff9bc7cf856aad727436c5`. It identifies three demonstrated utility gaps: build resources, source documentation browsing and terminal highlighting. New-project scaffolding remains release preparation. This audit does not establish complete CLI parity or require old command names, templates, manifests or installation machinery.

## Probe scope and reproduction

`tests/fixtures/clio/port-probes/cli.json` records the manifest, source, observations and SHA-256 hashes from the pinned repository. `scripts/probe-clio-cli.ts` checks those hashes before running. Extract `packages/cli`, `packages/highlight`, `packages/manifest`, `packages/core` and `packages/internals` into an isolated snapshot and restore the compiler dependency pins documented in [port completion](port-completion.md). Then run from the Kalandra repository root:

```sh
bun scripts/probe-clio-cli.ts /path/to/restored-clio-snapshot
```

The probe runs on Bun 1.3.12. It invokes selected original command bodies with import bindings supplied by a VM harness. It does not run yargs or recreate a historical Node installation. The compiler, manifest and highlighter execute from the restored sources/dependencies. Build uses its real `silent`, `skipNpmInstall` and `skipBundle` options. The harness supplies the JS platform's no-op build behavior and rejects unexpected install/process-launch attempts. No historical command body is repaired. It executes the generated arithmetic function directly, not through the old worker launcher.

For docs, scripted prompts select the first function and exit; this proves metadata/list/render behavior, not interactive terminal handling. Color capability is enabled for the highlighting probe. Temporary project files are removed. Kalandra's asset-copy result is printed as a dated observation, not asserted as a limitation that must persist.

Full old template downloads, Git dependency fetching, npm registry resolution, npm installation, run/host launchers, terminal keyboard behavior and remote template freshness remain unverified here. These limitations do not establish failures. Existing Kalandra tests provide independent evidence for current workflows; they are not retroactive evidence that old workflows ran.

## Order of work

1. PORT-005a completed: manifest-backed build resources with byte-preservation, destination validation and watch checks. See [resource behavior](port-completion.md#build-resources--port-005a).
2. PORT-005b completed: `docs <file.kalandra> [function] [--json]` inspects source declarations without executing user code.
3. PORT-005c completed: `highlight <file.kalandra> [--color auto|always|never]` uses current lexer spans and preserves source text.
4. Re-run port acceptance, then complete offline scaffolding, Tiramisu docs/site, packaging/install instructions and release polish.

Publishing and announcements follow the agreed release review. Language redesign remains after the revival release.
